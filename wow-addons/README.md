# WoW-Forever-Add-ons

Eigene Add-ons für **WoW Forever** (Interface 16001): LevelPilot (Levelrouten, Pfeil, Lichtstrahl), ProcAlarm,
EnhanceHUD, Blitzschild, MiniPost, ChatHoch – plus Routen-Werkzeuge, Tests und WeakAuras.

- Leitfaden für Claude: [`CLAUDE.md`](CLAUDE.md) · aktueller Stand: [`UEBERGABE.md`](UEBERGABE.md)
- Installation: Ordner aus `addons/` nach `World of Warcraft\_<Version>_\Interface\AddOns\` kopieren, WoW neu starten.
