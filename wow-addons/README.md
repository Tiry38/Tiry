# WoW-Forever-Add-ons

Eigene Add-ons für **WoW Forever** (Interface 16001): LevelPilot (Levelrouten, Pfeil, Lichtstrahl), **Tiry's Zentrale**
(Gold & Berufe), ProcAlarm, Schlaghagel, EnhanceHUD, Blitzschild, MiniPost, ChatHoch – plus Routen-Werkzeuge, Tests und WeakAuras.

- Leitfaden für Claude: [`CLAUDE.md`](CLAUDE.md) · aktueller Stand: [`UEBERGABE.md`](UEBERGABE.md)
- Tiry's Zentrale (eigener Ordner `TirysZentrale/`): Überblick [`ZENTRALE.md`](ZENTRALE.md), Anleitung [`ANLEITUNG.md`](ANLEITUNG.md),
  Prüfbericht [`AUDIT.md`](AUDIT.md), Änderungen [`CHANGELOG.md`](CHANGELOG.md), Ingame-Checkliste [`INGAME-TEST.md`](INGAME-TEST.md)
- Installation: Ordner aus `addons/` bzw. `TirysZentrale/` nach `World of Warcraft\_<Version>_\Interface\AddOns\` kopieren, WoW neu starten.
