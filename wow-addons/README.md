# WoW-Forever-Add-ons

Eigene Add-ons für **WoW Forever** (Interface 16001): LevelPilot (Levelrouten, Pfeil über echte Laufwege, Flug-Rat, Lichtstrahl), **RezeptRadar**
(Rezept-Berater Kochkunst & Leder, bis 7.0 „Tiry's Zentrale“), ProcAlarm, Schlaghagel, EnhanceHUD, Blitzschild, MiniPost, ChatHoch – plus Routen-Werkzeuge, Tests und WeakAuras.

- Leitfaden für Claude: [`CLAUDE.md`](CLAUDE.md) · aktueller Stand: [`UEBERGABE.md`](UEBERGABE.md)
- RezeptRadar (`addons/RezeptRadar/`): Überblick [`REZEPTRADAR.md`](REZEPTRADAR.md), Anleitung [`ANLEITUNG.md`](ANLEITUNG.md),
  Prüfbericht Zentrale 6.x [`AUDIT.md`](AUDIT.md), Änderungen [`CHANGELOG.md`](CHANGELOG.md), Ingame-Checkliste [`INGAME-TEST.md`](INGAME-TEST.md)
- LevelPilot (`addons/LevelPilot/`): Stand und Änderungen in [`UEBERGABE.md`](UEBERGABE.md), Ingame-Checkliste im zweiten Teil von [`INGAME-TEST.md`](INGAME-TEST.md)
- Installation: Ordner aus `addons/` nach `World of Warcraft\_<Version>_\Interface\AddOns\` kopieren, WoW neu starten.
