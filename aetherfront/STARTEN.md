# Aetherfront starten

## Spielen (Windows)
1. Auf GitHub im Repository unter **Actions → „Aetherfront – Windows-Spiel bauen“** den neuesten grünen Lauf öffnen.
2. Unten bei **Artifacts** „Aetherfront-Windows-Installer“ herunterladen, entpacken, `Aetherfront-Setup-….exe` doppelklicken.
3. Fertig – Aetherfront liegt auf dem Desktop.

Alternativ aus dem Quellcode (Node.js 22 nötig): im Ordner `aetherfront` einmal `npm install`, dann `npm start`.

## Mit Freunden spielen
1. Einer klickt im Hauptmenü auf **Mehrspieler → Spiel hosten**. Das Spiel startet den Server auf dem eigenen PC.
2. Der Host schickt den angezeigten **Einladungscode** und seine Adresse an die Freunde.
3. Freunde: **Mehrspieler → Beitreten**, Adresse und Code eingeben.
4. Der Host stellt Modus, Teams, Bots und Plätze ein und klickt **Starten**.

Spielen alle im selben WLAN, reicht die lokale Adresse (z. B. `192.168.178.20`).
Für Freunde über das Internet bitte einmal **SERVER-EINRICHTEN.md** befolgen (5 Minuten, kostenlos).

## Tastenbelegung (Standard)
- **Bauphase (Vogelperspektive):** Q W E R A S D F Vasallen · Klick setzen · C/V Aufwertungspfad 1/2 · X verkaufen ·
  1–7 Söldner · B Funke · K Königshalle · H König heilen · ↵ Bereit · Pfeiltasten/Mausrad Kamera · Pos1 eigene Bahn
- **Kampf (Held, wie World of Warcraft):** W/S vor/zurück · A/D drehen · Q/E seitwärts · rechte Maustaste lenken ·
  linke Maustaste Kamera drehen · beide Tasten laufen · Leertaste springen · Num automatisch laufen · Tab Ziel ·
  Rechtsklick angreifen · 1–5 Fähigkeiten · Esc Ziel löschen
