Mehrspieler Vorschau

Das Spiel ist bereits auf Online-Partien ausgelegt: Alle Aktionen laufen als Befehle über eine deterministische Simulation (Lockstep). Ein kleiner Relay-Server verteilt nur die Befehle – das spart Bandbreite und hält alle Spieler synchron. Leere Plätze übernehmen Bots.

Raum

Hinweis: Online-Partien sind experimentell. Server lokal starten mit npm run server (Port 7710). Für Freunde über das Internet muss der Port weitergeleitet oder ein Server gemietet werden.
