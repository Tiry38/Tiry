# NABE – Startseite (Entwurf: Kopfbereich)

Öffnen: `index.html` über einen lokalen Server (z. B. `python3 -m http.server` in diesem Ordner), dann http://localhost:8000.

- Orb: eigener WebGL-Shader (reagiert auf Zustände Bereit / Hört zu / Denkt nach / Spricht), Fallback ohne WebGL.
- Hörprobe: fiktives Beispielgespräch, Stimmen über die Sprachausgabe des Browsers (deutsche Stimme, falls vorhanden).
- Schriften (alle SIL OFL 1.1, Lizenzen in `fonts/`): Fraunces (Headlines), Manrope (Text), JetBrains Mono (Zahlen).
- Hell/Dunkel, `prefers-reduced-motion`, Tippflächen ≥ 44 px, keine externen Ressourcen, keine Tracker.
